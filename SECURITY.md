# Security policy

Security fixes target the latest stable npm release. Older versions are not
maintained separately; upgrade to the latest release to receive fixes.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/bhouston/yargs-file-commands/security/advisories/new).
If private reporting is unavailable, email ben@ben3d.ca with the affected version,
reproduction steps, impact, and any proposed mitigation. Do not open a public issue
containing exploit details before a fix is available.
