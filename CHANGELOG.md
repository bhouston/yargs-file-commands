# Changelog

Release notes are generated from Conventional Commits and published on
[GitHub Releases](https://github.com/bhouston/yargs-file-commands/releases).
Each npm package and GitHub release asset includes its generated CHANGELOG.md.
Release versions and generated notes are not committed back to the source branches.
